# Mimari dokümanlar

Bu dizin, sürümlü mimari teslimatlarını içerir. Kaynak kodu, operasyonel betikler
ve ortam sırları burada tutulmaz.

- `HLD_Yuksek_Seviye_Tasarim.docx`: yüksek seviye tasarım
- `LLD_Dusuk_Seviye_Tasarim.docx`: düşük seviye tasarım

Yeni mimari kararları ayrıca gözden geçirilebilir Markdown olarak `docs/` altında
eklenmelidir; ikili ofis belgeleri tek başına uygulama sözleşmesi değildir.
